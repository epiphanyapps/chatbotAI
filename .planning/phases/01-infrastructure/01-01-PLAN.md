<task type="checkpoint:human-action" gate="blocking">
  <name>Task 1: Gather Required Secrets</name>
  <what-needed>
  Before Terraform can deploy, you need these credentials:

  **1. DigitalOcean API Token (DO_TOKEN):**
  - Go to: https://cloud.digitalocean.com/account/api/tokens
  - Click "Generate New Token"
  - Name: "chatbotai-terraform"
  - Scopes: Read + Write
  - Copy and save the token

  **2. Stripe Test Key (STRIPE_SECRET_KEY):**
  - Go to: https://dashboard.stripe.com/test/apikeys
  - Copy "Secret key" (starts with sk_test_)

  **3. Alert Email:**
  - Your email for infrastructure alerts
  </what-needed>
  <resume-signal>Paste your secrets in format: DO_TOKEN=xxx STRIPE_KEY=sk_test_xxx EMAIL=you@email.com</resume-signal>
</task>

<task type="auto">
  <name>Task 2: Generate Cryptographic Secrets</name>
  <files>none</files>
  <action>
  Generate JWT and encryption keys using openssl:
  ```bash
  JWT_SECRET=$(openssl rand -hex 32)
  ENCRYPTION_KEY=$(openssl rand -hex 32)
  echo "JWT_SECRET_KEY=$JWT_SECRET"
  echo "ENCRYPTION_KEY=$ENCRYPTION_KEY"
  ```
  Store these securely - they're needed for Terraform and GitHub secrets.
  </action>
  <verify>Both 64-character hex strings generated</verify>
  <done>JWT_SECRET_KEY and ENCRYPTION_KEY generated</done>
</task>

<task type="auto">
  <name>Task 3: Create Terraform Backend Override</name>
  <files>terraform/backend_override.tf</files>
  <action>
  Create a local backend override file to bypass Terraform Cloud requirement for initial deployment:
  ```hcl
  # Temporary local backend - will migrate to remote later
  terraform {
    backend "local" {
      path = "terraform.tfstate"
    }
  }
  ```
  This allows deployment without Terraform Cloud account setup.
  </action>
  <verify>File exists at terraform/backend_override.tf</verify>
  <done>Backend override created</done>
</task>
